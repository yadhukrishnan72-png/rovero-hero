# Rovero hero page
Read `handoff.md` first, every session.

Static eSIM landing hero (no build step): `index.html`, `hero.css`, `hero.js`, `images/`.
Deployed on Vercel (project `rovero-hero`); repo: github.com/yadhukrishnan72-png/rovero-hero (private, branch `main`).

## Rules
- Never commit `.env*`, `.vercel/` or `Reference Image.png` (all in `.gitignore`; the PNG is a design reference only, not a deploy asset).
- Git/GitHub root is this `Rovero/` folder only. The parent `Documents/` is not a repo; don't touch sibling folders.
- Ask the user before creating repos or pushing; show the plan first.
- Brand tokens (#6415FE, Plus Jakarta Sans, #F7F7F7 canvas) live at the top of `hero.css`.
